# fes20 Spielewelt – Startseite (`ag_start`)

Die zentrale Startseite und das Spieleportal für [fes20.de](https://www.fes20.de).

## Verlinkte Spiele
- **Memory**: [/memory](https://www.fes20.de/memory) – Gedächtnisspiel
- **Moritz**: [/moritz](https://www.fes20.de/moritz) – Abenteuerspiel
- **Tier-Hotel**: [/tier-hotel](https://www.fes20.de/tier-hotel) – Wohlfühlspiel für Tierfreunde

## Deployment
Mit einem Klick auf die `deploy.bat` wird die Startseite automatisch auf den IONOS-Webspace in das Hauptverzeichnis (`/public`) übertragen.
